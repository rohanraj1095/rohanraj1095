## 🚀 Featured Project

### OwlSync — Smart Expense Analytics Platform
A modular backend following the Controller-Service-Repository pattern, with JWT + refresh token auth, Redis-based token blacklisting, RBAC, and OTP email verification.

- ⚡ Automated SMS transaction ingestion pipeline with Joi validation and idempotent MongoDB bulk writes
- 🚀 Multi-tier Redis caching (TTL + version-based invalidation) — **~50-60% reduction in DB query overhead**
- 📊 Complex MongoDB aggregation pipelines with compound indexing for fast date-range analytics
- 🤖 Groq/Llama LLM integration for spending forecasts and anomaly reports
- 🔒 Hardened with Helmet, CORS, express-rate-limit, and NoSQL injection sanitization

`Node.js` `Express.js` `MongoDB` `Redis` `JWT` `RBAC` `Groq/Llama` `Docker` `CI/CD`
